Data and Lexis diagrams

These examples use the built-in SEER datasets. Start with Example data, then continue in order.

Example data

MATISSE includes 16 example datasets from the US Surveillance, Epidemiology, and End Results (SEER) program. A Lexis diagram displays rates by age and calendar period. Start with example 16 to explore the workflow before using your own data. Run the code below to load the data and fill zero cells. Set DELTA to 2 or 5 to combine age and period intervals when the data are sparse.

Example = 16;      % 1x1 age-by-period Lexis diagram, e.g. "F melanoma NHW"
DELTA   = 1;        % chunk to 2x2 or 5x5 age/period blocks if the data are sparse

r = ratesdata(Example);
switch DELTA
    case 1
        R0 = r;
    case 2
        R0 = chunk(r, 'AgeBlock', 2, 'PerBlock', 2);
    case 5
        R0 = chunk(r, 'AgeBlock', 5, 'PerBlock', 5);
end

R = fill(R0);   % add a small value to any zero cells
disp(R)

Visualizing a Lexis diagram

MATLAB toolbox video: Watch Visualizing a Lexis diagram on YouTube (43 sec).

Two plots help you explore the same data. A heat map uses color to show the rates; a 3-D surface shows log rates. Run the Example data section first to create R. Then run this code: pcolor(R) draws the heat map, and surf(R) draws the surface.

figure('Position', [0 0 700 700])
pcolor(R)

figure('Position', [0 0 700 700])
surf(R)

Graphics settings can make patterns easier to see. Run the code below to compare the surface on the left with a heat map on the right. The heat map uses the nepal color scheme. Change one option at a time and inspect the result.

subplot(1, 2, 1)
surf(R)
colormap nepal
colorbar off
shading faceted

subplot(1, 2, 2)
pvp1 = ego('class', 'rates', 'method', 'pcolor');
pvp1.colormap  = 'nepal';
pvp1.colorbar  = 'southoutside';
pcolor(R, pvp1)

A property-value pair names a graphics setting and gives its value. The go options store these settings. Use ego to copy a plot method’s default settings, then edit the copy. MATISSE includes a 54-color line palette called clarinet. It also includes the africa and nepal color schemes, alongside MATLAB’s built-in choices.

Comparing several Lexis diagrams at once

Placing diagrams side by side helps you compare patterns across groups. Use thumbnail or vistagram with objects of the same size. Run the example below to compare breast cancer rates by estrogen receptor (ER) status and race. ER+ means receptor-positive; ER− means receptor-negative. NHB and NHW mean non-Hispanic Black and non-Hispanic White. The code combines the data into 2-by-2 age and period blocks, then displays log rates.

r4 = ratesdata([1 3 2 4]);   % ER+ NHB, ER+ NHW, ER- NHB, ER- NHW
t4 = cell(1, 4);
for i = 1:4
    r4{i} = chunk(r4{i}, 'AgeBlock', 2, 'PerBlock', 2);
    t4{i} = type(r4{i}, 'comp', 'lr');   % log rates
end

figure('Position', [0 0 1200 600])
thumbnail(t4)

Standard plots

The four standard plots show the same rates from four angles. Each plot uses a log scale. Each is a slice through the Lexis diagram, so the Lexis diagram live script shows how they connect.

Plot What it shows Command
rpa Rates versus period, by age salsa(R, 'rpa')
rap Rates versus age, by period salsa(R, 'rap')
rca Rates versus cohort, by age salsa(R, 'rca')
rac Rates versus age, by cohort salsa(R, 'rac')

Use ftp(R) to draw all four at once. The two cohort plots (rca and rac) need age groups and calendar periods of equal width, such as 5-year age groups with 5-year periods. If the widths differ, ftp draws the two plots that remain defined. For options, run help rates/ftp and help rates/salsa.

Estimable functions

Fit the new APC model to a rates object with apc. The model provides estimable functions (EFs). These are summaries of age, period, and cohort effects that the data can determine. Run plot(M) on the fitted model M to draw six of them in one 2-by-3 panel:

Panel position Estimable function ef code
Row 1, column 1 Fitted Temporal Trends (FTT) 'ftt'
Row 1, column 2 Fitted Cohort Pattern (FCP) 'fcp'
Row 1, column 3 Local Drifts (LD) 'ld'
Row 2, column 1 Longitudinal Age Curve (LAC) 'lac'
Row 2, column 2 Cross-Sectional Age Curve (CAC) 'cac'
Row 2, column 3 Gradient Shifts (GS) 'gs'

Use ef(M, 'Comp', 'lac') to return one estimable function as a matrix object, which holds the values and their uncertainty. MATISSE provides all the outputs of the NCI web tool and more. The new age-period-cohort model defines each function. For options, run help apc/ef and help apc/plot.

Advanced methods

These methods build on the new APC model. Each has a short description and a method paper. Live scripts will be added as they become available.

Smoothing with SIFT

Rates are noisy when case counts are small. SIFT (singular-value adaptive kernel filtration) smooths a matrix of rates with a panel of kernel operators. It combines their results into denoised values with an optimal balance of bias and variance. Read Smoothing methods for Lexis diagrams to learn the method.

Semiparametric APC with SAGE

SAGE (semiparametric age-period-cohort analysis) works in two steps. First, it smooths the observed rates with SIFT. Then it fits the new APC model to the smoothed rates. SAGE estimable functions are smoother than those from the standard model, which helps most when cell counts are modest. Run sage(R) to start. Read Semiparametric age-period-cohort analysis to learn the method.

Comparative APC analysis

Comparative APC analysis compares rates from several groups, such as strata defined by sex, race, or ER status, over the same Lexis diagram. The built-in breast cancer examples are a good place to try it.

  • EPIPHANY explores the data. It finds the best-fitting way to split the groups into subsets with proportional rates and single groups that are not proportional. You can then group estimable functions as equal, parallel, or unequal.
  • CAPRICORN tests hypotheses. It determines whether the rates are jointly proportional by age, period, or cohort. Proportional rates are easier to interpret and give more efficient estimates. A lack of proportionality shows that the groups differ significantly.

Read Comparative age-period-cohort analysis to learn the methods. For options, run help epiphany/epiphany and help capricorn/capricorn.
