What the workshop is

The workshop uses this website as its guide. Attendees work through selected modules with the team, run the code themselves, and ask questions as they go. The material stays online afterwards, so you can finish at your own pace.

It is for epidemiologists, surveillance and registry researchers, and biostatisticians. No experience with age-period-cohort analysis is needed.

Preliminary plan

  • Day 1: overview and APC primer. What APC analysis is for, the New APC model, a tour of this course site, and how to prepare registry data for the NCI web tool.
  • Day 2: how to move forward. Comparative methods, the SAGE method, a high-level look at the theory, and the directions the methods can take you.
  • Optional follow-up. A smaller drop-in session for anyone who wants to go deeper into the theory and methods.

Time is set aside for questions at the end of each session. Recorded lectures will be posted on the MATISSE YouTube channel.

Get ready now

  • Read Module 1 if Lexis diagrams are new to you.
