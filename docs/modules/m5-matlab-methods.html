What is not in R yet

matisseR (version 0.1.0) ports the core of MATISSE: rates objects, the New APC model with five estimable functions, and CAPRICORN. It adds the generation and share tools you met in Module 4. Several other MATISSE methods exist only in the MATLAB toolbox, which Philip S. Rosenberg wrote and which remains the reference implementation.

Method What it does MATLAB Read more
Smoothing Lexis diagrams Denoises a matrix of rates with a panel of kernel filters, keeping an optimal balance of bias and variance sift, panko Smoothing methods for Lexis diagrams
SAGE (semiparametric APC) Smooths the observed rates with SIFT, then fits the New APC model to the smoothed rates. Gives smoother estimable functions, which helps most when counts per cell are modest sage Cancer incidence trends in successive social generations, JAMA Netw Open 2024
EPIPHANY (exploratory comparative APC) Given K groups, finds the best-fitting partition into proportional subsets and non-proportional singletons, so you can group estimable functions as equal, parallel or unequal epiphany Comparative APC analysis, BMC Med Res Methodol 2023
Joinpoint regression Piecewise linear trends with the number and location of knots chosen from the data joinpoint Joinpoint method paper
Standard plots and summary curves The four standard plots of rates (versus period, age or cohort) and marginal summary curves rates methods salsa, ftp, line, sierra, scan Toolbox guide
More estimable functions Gradient shifts, deviations, rate ratios, and likelihood-ratio and Wald tests for APC submodels apc methods ef, lrt, wald, aic Toolbox guide
NoteA note on validation

matisseR has an internal test suite, and a folder in the package sets up a side-by-side comparison of R and MATLAB results on the same data. The MATLAB side of that comparison has not been run yet, so treat the two as equivalent in method but not yet cross-checked number by number.

The MATISSE system map shows where every class and method sits. The R package covers part of it.

Choose a tool

You want to… Use
Fit the New APC model, read the estimable functions, compare groups with CAPRICORN R (matisseR) or MATLAB; the methods are the same
Compare social generations, cohort shares, or pool results across many populations in a script R: these tools are in matisseR only
Run many analyses reproducibly in a pipeline R
Smooth sparse rates, fit SAGE, run EPIPHANY, fit joinpoint models, draw the four standard plots MATLAB until they are ported

You do not have to choose once. A common workflow smooths and fits in MATLAB, then moves rate tables to R for the generation and pooling steps.

Self-check3 min

Self-check

What does SAGE do?

  1. It compares groups with likelihood-ratio tests.
  2. It smooths the observed rates with SIFT and then fits the New APC model to the smoothed rates.
  3. It draws the four standard plots.

SAGE is a two-step approach: denoise the rates, then fit the New APC model. Its estimable functions are smoother than those of the standard model, which helps most when counts are modest.

Which of these tools is in matisseR but not in the MATLAB toolbox?

  1. Social generation contrasts and cohort shares.
  2. SIFT smoothing.
  3. Joinpoint regression.

The generation and share tools are additions in matisseR. SIFT, SAGE, EPIPHANY and joinpoint are in the MATLAB toolbox only, for now.
