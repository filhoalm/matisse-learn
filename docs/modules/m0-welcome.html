Welcome

Rates of disease and death, such as cancer incidence or mortality, change with age, with calendar period, and with birth cohort, the group of people born in the same years. Age-period-cohort (APC) analysis separates these three time scales so that you can ask better questions. Is a rise in rates a change affecting everyone at once, or a pattern carried by younger generations? Are two populations following the same trend, or different ones?

matisseR is an R toolbox for disease surveillance, built for this kind of analysis. It is an R port of MATISSE, the MATLAB toolbox for vital rates surveillance written by Philip S. Rosenberg, and it adds tools for comparing social generations and cohort shares. You will learn it by using it on synthetic examples and on real research projects.

Reading10 min

Set up R and matisseR

You need R 4.1 or later. RStudio is optional but convenient. Install the packages the course uses, then install matisseR from its GitHub repository:

install.packages(c("data.table", "ggplot2", "patchwork", "scales", "remotes"))
remotes::install_github("filhoalm/matisseR")

matisseR itself needs only data.table. The other packages are for plotting. If R asks whether to update other packages while installing, you can skip the update.

Hands-on lab10 min

Check your setup

Load the package and confirm the version:

library(matisseR)
packageVersion("matisseR")
[1] '0.1.0'

The package ships eight synthetic datasets for learning. Call matisse_example() with no argument to see the index:

matisse_example()[, .(number, site, sex, population, ages, periods, cases)]
number site sex population ages periods cases
1 melanoma F A 50 29 16339
2 melanoma F B 50 29 9905
3 melanoma F C 50 29 3203
4 melanoma F D 50 29 9674
5 breast F A 50 29 113679
6 lung F A 50 29 34885
7 all cancers F A 50 29 423369
8 thyroid M C 50 29 759

Each dataset is a Lexis diagram: rates by single year of age (35 to 84) and single calendar year (1991 to 2019), generated from known age-period-cohort surfaces. They are not registry data. Because the true patterns are known, you can check what a method recovers. Open one:

R <- matisse_example(1)
rates_uni(R)[, .(object, ages, periods, cell, events, person_years)]
object ages periods cell events person_years
Synthetic melanoma F A 35-84 1991-2019 1x1 16339 56075673

If you see the table above, your setup works. You will use matisse_example(1), a melanoma-like pattern in women, in the next module.

Self-check3 min

Self-check

Which function lists the example datasets that ship with matisseR?

  1. matisse_example()
  2. csv2rates()
  3. rates_make()

Called without an argument, matisse_example() returns the index of the eight datasets. csv2rates() reads a file you already have, and rates_make() builds a rates object from your own table.

Are the example datasets real cancer registry data?

  1. Yes, they come from the SEER program.
  2. No, they are synthetic: counts drawn from known age-period-cohort patterns.
  3. Yes, they come from European registries.

They are synthetic. That is useful for learning, because the true net drift of each surface is known and listed in the index, so you can check your results. (The MATLAB toolbox ships real SEER data instead.)
